# ภารกิจพิชิตยาเสพติด (Drug-Free Hero)

เกมออนไลน์ 2 มิติ แนวผจญภัยและตอบคำถาม เพื่อรณรงค์ต่อต้านยาเสพติด สำหรับนักเรียนระดับมัธยมศึกษา พัฒนาด้วย React, TypeScript, Tailwind CSS, และ Vite

---

## 🚀 วิธีการนำเว็บไซต์ขึ้นออนไลน์บน GitHub (GitHub Pages)

โปรเจกต์นี้ได้รับการตั้งค่า `base: './'` และไฟล์ **GitHub Actions Workflow** (`.github/workflows/deploy.yml`) ไว้อย่างสมบูรณ์แล้ว สามารถนำขึ้นออนไลน์ได้ฟรีด้วยขั้นตอนดังนี้:

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. เข้าเว็บไซต์ [github.com](https://github.com/) และเข้าสู่ระบบ
2. กดปุ่ม **New** (หรือเครื่องหมาย `+` ด้านขวาบน) เพื่อสร้าง Repository ใหม่
3. ตั้งชื่อ Repository เช่น `drug-free-hero` หรือ `anti-drug-game`
4. เลือกเป็น **Public**
5. กดปุ่ม **Create repository**

### ขั้นตอนที่ 2: อัปโหลดโค้ดขึ้น GitHub
เปิด Terminal หรือ Command Prompt ในเครื่องของคุณที่โฟลเดอร์โปรเจกต์นี้ แล้วพิมพ์คำสั่ง:

```bash
git init
git add .
git commit -m "Initial commit: Drug-Free Hero Game"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้GitHubของคุณ>/<ชื่อRepositoryของคุณ>.git
git push -u origin main
```

*(หรือหากดาวน์โหลดเป็นไฟล์ ZIP สามารถกด **Upload files** ลากไฟล์ทั้งหมดขึ้นบนหน้าเว็บ GitHub ได้โดยตรง)*

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. ในหน้า Repository ของคุณบน GitHub ให้คลิกที่แท็บ **Settings** (การตั้งค่า)
2. เมนูด้านซ้าย เลือกเมนู **Pages**
3. ตรงหัวข้อ **Build and deployment**:
   - ช่อง **Source** ให้เปลี่ยนจาก *Deploy from a branch* เป็น **GitHub Actions**
4. ระบบจะทำการรัน Workflow อัตโนมัติ (สามารถดูความคืบหน้าได้ที่แท็บ **Actions**)
5. เมื่อเสร็จสิ้น (ประมาณ 1 นาที) คุณจะได้รับลิงก์เว็บไซต์ออนไลน์ทันที เช่น:
   👉 `https://<ชื่อผู้ใช้ของคุณ>.github.io/<ชื่อRepositoryของคุณ>/`

## 🎮 รายละเอียดเนื้อหาในเกม (5 ภารกิจ)

1. **ด่านที่ 1: คลังความรู้ต้านยาเสพติด (Quiz Adventure)**
   - ทดสอบความรู้เรื่องยาบ้า, ยาไอซ์, บุหรี่ไฟฟ้า, สารระเหย และสายด่วน 1386
2. **ด่านที่ 2: แยกแยะพฤติกรรมเสี่ยงและเหมาะสม (Sorting Challenge)**
   - คัดแยก 8 พฤติกรรมในชีวิตประจำวันเพื่อความปลอดภัย
3. **ด่านที่ 3: ฝึกทักษะการปฏิเสธเมื่อถูกชวน (Refusal Dialogue RPG)**
   - จำลองการปฏิเสธตามสูตร 3 สเต็ปฮีโร่ (ปฏิเสธหนักแน่น -> ให้เหตุผล -> ชวนทำสิ่งอื่นหรือเดินผละออก)
4. **ด่านที่ 4: ทางแยกชีวิต ห่างไกลยาเสพติด (Life Pathways)**
   - การตัดสินใจเมื่อเผชิญความเครียด ปัญหาเพื่อน และเวลาว่าง
5. **ด่านที่ 5: ภารกิจสร้างชุมชนปลอดยาเสพติด (Community Mission)**
   - แผนที่ชุมชน 4 จุด ฟื้นฟูโรงเรียน ลานกีฬา ติดป้ายสายด่วน และจัดเวทีดนตรีสร้างสรรค์

## 🏆 จุดเด่น
- มีตัวละครให้เลือกเล่น 4 สไตล์ (ไอดิน, ฟ้าใส, ก้องภพ, มิ้นท์)
- มีระบบสะสมคะแนนและดาว (สูงสุด 15 ดาว)
- ได้รับ **เหรียญเกียรติยศฮีโร่ต้านยาเสพติด** และ **เกียรติบัตรรับรองผล** สามารถสั่งพิมพ์ได้
- ระบบเสียง Procedural Web Audio API ในตัว พร้อมปุ่มเปิด/ปิดเสียง
- พี่ฮีโร่ที่ปรึกษา (AI Drug-Free Mentor) ให้คำแนะนำและกำลังใจ
- รวมเบอร์สายด่วนสำคัญ: **1165** (บำบัดยาเสพติด), **1386** (แจ้งเบาะแส ป.ป.ส.), **1323** (สุขภาพจิต), **1300** (ศูนย์ช่วยเหลือสังคม)
